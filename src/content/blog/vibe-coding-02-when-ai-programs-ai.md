## Time for a Review

After six weeks of intensively programming an AI-Application for text-to-graph conversion, I would love to share my experiences.

I checked out **Cline** (formerly known as Claude) as an integrated coding robot in VS Code.

### Results
- **~3500 lines of code** generated by Cline
- **0 lines** by me
- **$135** for tokens (2-3x higher when LLM companies start charging full cost)

## Was it Efficient?

Without Cline I would not have been able to do anything close to that.

If a good coder would have been more efficient, would have created better code, nicer frontend? Anyway, AI-Development is still running fast.

## The Biggest Hurdle

One of the biggest hurdles: **Limited oversight for the structure of the whole project**, for maintaining interfaces & data formats.

Don't get me wrong - Cline managed to implement changes spanning 6 files and a dozen functions.

## The Interesting Part

If you are having an issue with an AI, **ask the AI!**

So I tasked Cline to define the crucial data formats or describe a crucial concept of the project and gave him the advice to check those informations first before starting changes.

## So what if...

...you generate a plausible structure for a software project, with the major functional elements and definition of the information exchange between them - and use this as a guideline for your programming robot?

**Sounds a bit like classical systems engineering, doesn't it?**

## So what if...

...you generate this structure **with AI support**, which basically is the purpose of my Summer School Project?

Yes, then **AI advises AI to create an AI Application**. Complex? Maybe, but possible.
